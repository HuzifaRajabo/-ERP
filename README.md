# ERP System (نظام إدارة الموارد المؤسسية)

نظام متكامل لإدارة الموارد المؤسسية (ERP) مبني باستخدام Flutter، مصمم للعمل داخل المؤسسة بشكل محلي عبر SQLite دون الحاجة إلى خادم مركزي. يغطي التطبيق كافة الجوانب التشغيلية والمالية الأساسية مع التركيز على الكفاءة والسرعة.

## نبذة سريعة

- **اللغة**: العربية
- **الاتجاه**: RTL (من اليمين إلى اليسار)
- **التقنية**: Flutter + GetX + SQLite
- **النمط المعماري**: Repository + Controller + View
- **نوع النشر**: تطبيق محلي على الجهاز (Local Offline Application)
- **البيئة**: متوافق مع كافة أنظمة التشغيل المدعومة من Flutter.

الإصدار الحالي في ملف `pubspec.yaml` هو: `2.1.10+1`

## الميزات الشاملة للنظام

### 1. إدارة المنتجات والتصنيفات
- تصنيف المنتجات وإدارة الفئات (Categories) بمرونة عالية.
- دعم وحدات القياس المختلفة للمنتجات.
- تتبع المنتجات عبر التواريخ أو الدفعات (Batches).
- تخزين بيانات متكاملة: الاسم، الوصف، التكلفة، سعر البيع، تاريخ الإنشاء.
- بحث متقدم وفرز دقيق للمنتجات.

### 2. إدارة المستودعات والمخزون
- **تعدد المستودعات**: إمكانية إنشاء وإدارة أكثر من مستودع.
- **نقل المخزون (Stock Transfer)**: نقل المنتجات بمرونة بين المستودعات مع توثيق الحركات.
- **إدارة التالف/الهالك (Stock Loss)**: تسجيل الكميات التالفة وخصمها من المخزون مع توثيق أسباب التلف لتقييم الخسائر.
- متابعة الكميات المتاحة وحساب حركة الدخول والخروج بشكل فوري.

### 3. الفواتير والمبيعات والمشتريات
- دعم شامل لفواتير المبيعات والمشتريات.
- ربط الفواتير بأطراف محددة ومستودعات معينة.
- تحقق فوري من توفر المخزون قبل إتمام المبيعات لتفادي الأخطاء.
- توثيق تفصيلي لكل فاتورة (المنتجات، الكميات، السعر الإفرادي والإجمالي، الملاحظات).
- معالجة الدفعات النقدية والآجلة بشكل مباشر من شاشة الفاتورة.

### 4. إدارة الأطراف (العملاء والموردين)
- إضافة الأطراف وتصنيفها: `CUSTOMER`, `SUPPLIER`, أو `BOTH`.
- تسجيل بيانات تفصيلية (الاسم، أرقام الهواتف، العناوين).
- متابعة حسابات كل طرف ومديونياته وفواتيره المرتبطة.

### 5. التعبئة والتغليف (Packaging)
- وحدة تصنيع/تجميع مصغرة لسحب مواد خام من المستودع وتحويلها لمنتجات نهائية (جاهزة للبيع).
- حساب تكاليف التعبئة وإضافة المنتج النهائي للمستودع بشكل آلي بمجرد تأكيد العملية.

### 6. المدفوعات والديون والمالية
- تسجيل وتتبع الدفعات المالية (`INBOUND` / `OUTBOUND`).
- متابعة مستمرة للديون (ما لنا وما علينا).
- ربط المدفوعات بالفواتير لمعرفة الرصيد المتبقي بدقة.

### 7. إدارة المرتجعات
- معالجة مرتجعات المبيعات والمشتريات وربطها بالفواتير الأصلية.
- إعادة المخزون بشكل تلقائي وتحديث مديونية الطرف وفقاً للمرتجع.

### 8. إدارة المصاريف
- تسجيل المصروفات التشغيلية للمؤسسة.
- تصنيف المصاريف (نقل، وقود، رواتب، إيجار، كهرباء، إنترنت، صيانة، أخرى).

### 9. الإشعارات والتقارير
- **نظام الإشعارات (Notifications)**: تنبيهات داخلية في النظام (مثال: تنبيهات نقص المخزون أو اقتراب نفاذه).
- **التقارير التحليلية**: توليد تقارير شاملة (أرباح وخسائر، مبيعات، مشتريات، ديون، مخزون) لفترات زمنية محددة.
- إمكانية تصدير التقارير إلى ملفات PDF للطباعة والمشاركة.

### 10. إعدادات النظام والمظهر
- تخصيص ملف الشركة (Company Profile) وإضافة شعار المؤسسة وتفاصيلها لتظهر في التقارير والفواتير.
- إعدادات المظهر (Theme Settings) لتخصيص الألوان وتجربة الاستخدام.

## المكونات الهندسية للنظام

يعتمد النظام بنية نظيفة وقابلة للتطوير (Layered Architecture):

- `lib/views/` : واجهات المستخدم المقسمة حسب الميزات (Products, Invoices, Warehouses, Packaging, etc).
- `lib/controllers/` : منطق التطبيق وإدارة الحالة باستخدام GetX.
- `lib/repositories/` : طبقة التجريد للتعامل مع قاعدة البيانات وتطبيق قواعد العمل.
- `lib/models/` : نماذج البيانات الخاصة بجداول النظام.
- `lib/core/` : ملفات النظام الأساسية للخدمات وإدارة أخطاء القاعدة والمرافق العامة (`utils`).
- `lib/bindings/` : تسجيل التبعيات لربط الواجهات بمتحكماتها وتوفير الموارد بكفاءة.

## بنية قاعدة البيانات

يتم استخدام SQLite كقاعدة بيانات محلية رئيسية: `erp_mvp.db`

من أهم الجداول:
- `products`, `categories`, `product_units`, `batches` (بيانات المنتجات وتفريعاتها)
- `warehouses`, `inventory_transactions`, `stock_transfers`, `stock_losses` (إدارة المستودعات والحركة)
- `parties` (العملاء والموردين)
- `invoices`, `invoice_items` (الفواتير والتفاصيل)
- `returns`, `return_items` (المرتجعات)
- `payments`, `expenses`, `financial_transactions` (المالية والديون)

**ملاحظات تقنية**:
- تم تفعيل `PRAGMA foreign_keys = ON` لضمان سلامة البيانات (Referential Integrity).
- يتم إدارة التحديثات والترقيات بفعالية عبر دوال `onUpgrade`.

## المتطلبات التقنية وطريقة التشغيل

1. **البيئة**: يحتاج النظام إلى Flutter SDK و Dart SDK.
2. **المحرر**: يمكن استخدام VS Code أو Android Studio.
3. **التثبيت**:
   ```bash
   flutter pub get
   ```
4. **التشغيل**:
   ```bash
   flutter run
   ```
5. **استخراج ملف التنفيذ (مثال APK)**:
   ```bash
   flutter build apk
   ```

## الخلاصة

هذا المشروع هو حل ERP متكامل، لا يتطلب خوادم سحابية، مما يضمن الخصوصية الكاملة وسرعة الوصول للبيانات محلياً. بنيته الحديثة باستخدام Flutter و GetX تجعله قابلاً للتطوير المستمر ليناسب الشركات الصغيرة والمتوسطة، مع إمكانية ربطه مستقبلاً بقواعد بيانات مركزية إن لزم الأمر.
