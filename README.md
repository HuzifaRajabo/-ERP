# ERP System

نظام إدارة الموارد المؤسسية (ERP) مبني باستخدام Flutter، مصمم للعمل داخل المؤسسة بشكل محلي عبر SQLite دون الحاجة إلى خادم مركزي. التطبيق يركز على إدارة العمليات التشغيلية الأساسية مثل المنتجات، الأطراف، الفواتير، المخزون، المصاريف، الديون، والربح والخسارة.

## نبذة سريعة

- اللغة: العربية
- الاتجاه: RTL (من اليمين إلى اليسار)
- التقنية: Flutter + GetX + SQLite
- النمط المعماري: Repository + Controller + View
- نوع النشر: تطبيق محلي على الجهاز

الإصدار الحالي في ملف `pubspec.yaml` هو: `2.1.10+1`

## الميزات الأساسية

### 1. إدارة المنتجات
- إضافة منتج جديد
- تعديل وحذف المنتج
- البحث حسب الاسم
- عرض المنتجات بترتيب منظم
- دعم البيانات الأساسية مثل الاسم، الوصف، التكلفة، سعر البيع، وتاريخ الإنشاء

### 2. إدارة الأطراف
- إدارة العملاء والموردين وكلاهما
- إنشاء الأطراف وتحديثها
- تخزين بيانات مثل الاسم، الهاتف، العنوان، والنوع (`CUSTOMER`, `SUPPLIER`, `BOTH`)
- ربط الفواتير بالأطراف

### 3. إدارة الفواتير
- دعم فواتير المبيعات والمشتريات
- تسجيل تفاصيل الفاتورة (الطرف، الإجمالي، المدفوع، الحالة، الملاحظات، التاريخ)
- إدراج سطور الفاتورة (منتج + كمية + سعر)
- التحقق من صحة البيانات قبل الحفظ
- منع إنشاء فاتورة بدون سطور
- التحقق من توفر المخزون أثناء البيع

### 4. إدارة المخزون
- تسجيل حركة المخزون عند إنشاء الفواتير
- متابعة الكميات المتاحة
- دعم أنواع الحركات:
  - شراء
  - بيع
  - مرتجع مبيعات
  - مرتجع مشتريات
- حساب حركة الدخول والخروج للمنتجات

### 5. المدفوعات والديون
- متابعة المدفوعات المرتبطة بالفواتير
- تصنيف المدفوعات إلى `INBOUND` و `OUTBOUND`
- متابعة ما يدين به العملاء للمؤسسة وما تدين به المؤسسة للموردين
- حساب الرصيد المتبقي في كل فاتورة

### 6. إدارة المصاريف
- تسجيل المصاريف
- تصنيف المصاريف مثل:
  - TRANSPORT
  - FUEL
  - SALARIES
  - RENT
  - ELECTRICITY
  - INTERNET
  - MAINTENANCE
  - OTHER
- تجميع المصاريف في التقارير النهائية

### 7. إدارة المرتجعات
- مرتجعات المبيعات
- مرتجعات المشتريات
- ربط كل مرتجع بالفاتورة الأصلية
- تحديث قيمة الفاتورة المرتبطة عند وجود عائد
- تسجيل التأثير في المخزون والمالية

### 8. التقارير والتحليل المالي
- ملخص يومي / أسبوعي / شهري / سنوي
- تقارير المبيعات والمشتريات
- تقرير الأرباح والخسائر
- تقرير الديون
- تقرير قيمة المخزون
- تصدير التقارير إلى PDF

## المكونات الرئيسية للنظام

### هندسة التطبيق
النظام مبني على طبقات واضحة:

- `lib/views/` : واجهات المستخدم
- `lib/controllers/` : منطق التطبيق باستخدام GetX
- `lib/repositories/` : التعامل مع قاعدة البيانات وإنشاء قواعد العمل
- `lib/models/` : نماذج البيانات
- `lib/core/database/` : إعداد واستعلامات SQLite
- `lib/core/services/` : خدمات مساعدة مثل `AppEventBus`
- `lib/bindings/` : تسجيل التبعيات والربط بين Controllers و Views

### الواجهات الأساسية
- الشاشة الرئيسية (`MainScreen`)
- شاشة المنتجات
- شاشة الأطراف
- شاشة الفواتير
- شاشة المخزون
- شاشة المصاريف
- شاشة الديون
- شاشة التقارير

## بنية قاعدة البيانات

يتم استخدام SQLite كقاعدة بيانات محلية، مع اسم قاعدة البيانات الرئيسي:

- `erp_mvp.db`

### الجداول الأساسية

| الجدول | الوظيفة |
|---|---|
| `products` | المنتجات |
| `parties` | الأطراف (عملاء / موردين) |
| `invoices` | الفواتير |
| `invoice_items` | تفاصيل الفواتير |
| `inventory_transactions` | حركة المخزون |
| `returns` | المرتجعات |
| `return_items` | تفاصيل المرتجعات |
| `payments` | المدفوعات |
| `expenses` | المصاريف |
| `financial_transactions` | الحركات المالية العامة |

### ملاحظات مهمة
- يتم تفعيل `PRAGMA foreign_keys = ON`
- تم اعتماد العلاقات الخارجية بين الجداول
- يتم إدخال فهارس معينة لتحسين الأداء والاستعلامات
- يتم التعامل مع ترقيات قاعدة البيانات عبر `onUpgrade`

## تدفق العمل في النظام

```text
المستخدم
  ↓
واجهة التطبيق (View)
  ↓
Controller
  ↓
Repository
  ↓
SQLite Database
  ↓
إرجاع النتيجة إلى Controller
  ↓
تحديث الواجهة مباشرة عبر GetX
```

### مثال عملي: إنشاء فاتورة بيع
1. يقوم المستخدم بإنشاء فاتورة جديدة
2. يحدد الطرف والمنتجات والكميات والسعر
3. يتحقق النظام من وجود الطرف والمنتجات
4. يتحقق من توفر المخزون
5. يتم حفظ الفاتورة في قاعدة البيانات
6. يتم تسجيل حركة المخزون
7. يتم تسجيل الدفع إن وجد
8. يتم تحديث التقارير والواجهات تلقائيًا

## الخلاصة

هذا المشروع هو نظام ERP محلي كامل ومناسب لإدارة العمليات الأساسية للمؤسسة في بيئة صغيرة أو متوسطة. يدمج التطبيق بين إدارة المنتجات، الأطراف، الفواتير، المخزون، المصاريف، الديون، والتقارير المالية في بنية منظمة وسهلة التطوير.

إن بناء المشروع على Flutter مع GetX و SQLite يمنحه سرعة تطوير جيدة، سهولة تحديث البيانات، ومرونة عالية في توسيع النظام مستقبلاً.
